## Recommended Execution Order

1. **Plan 001 (`001-button-press-feedback.md`)**: Foundation step. Defines the shared `--ease-out` and `--ease-in` curves in `src/index.css` and immediately speeds up press feedback across every button in the application.
2. **Plan 002 (`002-puzzle-toast-duration.md`)**: Fixes the sluggish 700ms toast into a crisp 220ms reward.
3. **Plan 003 (`003-navbar-profile-dropdown.md`)**: Anchors menu origin to the avatar trigger and removes the jarring unmount snap.
4. **Plan 005 (`005-puzzle-hint-accordion.md`)**: Prevents the 70px vertical layout jump when opening clues.
5. **Plan 004 (`004-endgame-celebration-spring.md`)**: Replaces the looping bounce in endgame victory with a single damped pop.

## How to Execute

To execute any plan with an autonomous subagent and verify the diff against Emil Kowalski's craft standard, run:
```bash
improve-animations execute plans/001-button-press-feedback.md
```
Or hand the Markdown file directly to any coding assistant.
